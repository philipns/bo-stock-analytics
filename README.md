# BO Stock Analytics — Streamlit MVP

Personal research dashboard for IDX breakout strategy.

## Features
- Pivot 4/4 breakout scanner
- AUTO / MANUAL / AUTO+MANUAL universe
- Fit Score ranking
- Setup status
- Per-stock Breakout vs Buy & Hold
- Portfolio research snapshot
- IHSG benchmark
- Tablet-friendly Streamlit UI

## Deploy on Streamlit Community Cloud
1. Create a GitHub repository.
2. Upload `app.py` and `requirements.txt`.
3. Open Streamlit Community Cloud.
4. Create app from your GitHub repo.
5. Main file: `app.py`.

Data source: Yahoo Finance via yfinance.
